# Styling-Vorlagen

Diese Bibliothek sammelt kompakte, vollständig nutzbare Style-Beispiele nach fachlichem Gebiet. Jede Vorlage bleibt bewusst klein, dokumentiert die gestalterische Entscheidung und nennt sinnvolle Varianten, damit Muster schnell übernommen oder angepasst werden können.

## Gebiete

- `contact-forms/` – Kontakt- und Anfrageformulare
- `resumes/` – Lebenslauf-, Profil- und Vita-Abschnitte

Neue Vorlagen sollen zuerst einem bestehenden Gebiet zugeordnet werden. Ein neues Gebiet wird nur angelegt, wenn sich der Anwendungsfall fachlich deutlich von den vorhandenen Kategorien unterscheidet. Titel, Beschreibungen, Begründungen, Optionen und sichtbare Beispieltexte werden grundsätzlich auf Deutsch formuliert; technische Bezeichner und Code-Syntax bleiben unverändert, wenn eine Übersetzung unüblich oder technisch falsch wäre.
