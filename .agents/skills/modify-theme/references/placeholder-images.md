# Curated placeholder images

Read this reference when a theme demo has no supplied image or the user permits replacing a reference image. These URLs are content candidates, not theme assets: place them in demo markup or data and keep component styling independent of the selected image.

## Selection rules

- For a missing doctor or employee portrait, always use the matching female or male portrait fallback below.
- For other missing images, choose the closest content purpose. Use the generic fallback when no topic-specific candidate fits.
- Write alt text for the image's actual purpose in the demo; do not derive it from the filename.
- Do not search for or download another stock image unless this list lacks a suitable category and the user approves an alternative.
