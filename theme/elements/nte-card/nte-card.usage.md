# Cards

Der öffentliche Theme-Entry registriert den automatischen Default.
Die Slots und vorhandenen Modifier beschreibt
[`style-default`](_style-default.usage.md).

```markdown
## Einblick
{: layout="nte-card" }

Ein kurzer Überblick.

[Weiterlesen](/einblicke.html)
{: slot="footer" }
```
