# Zentrierter Kampagnen-Hero mit Formular

`style-campaign` stapelt Aussage, Vertrauenssignale und Formular in einer
zentrierten Komposition. Optionale `.hero-copy`, `.trust-list` und
`.hero-form` gehören zum dokumentierten Content-Muster. Die gleiche
Darstellung kann Produktstarts und Beratungsangebote einleiten.

```markdown
## Gemeinsam starten
{: layout="ntl-hero.style-campaign" }

Ein überzeugender Nutzen in einem Satz.

### Kontakt
{: layout=".hero-form" }

#[nte-input type="email" name="email" label="Ihre E-Mail"]
```
