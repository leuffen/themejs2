# Hero mit nativen Hintergrund- und Inhaltsslots

Verwendet die Nextrap-Hero-Baseline. Hintergrundbilder gehören nach `bg`;
ohne Style-Klasse wählt die Komponente automatisch diesen Default.

```markdown
## Willkommen
{: layout="ntl-hero" }

Ein kurzer Einstieg.

![Blick in die Praxis](/assets/praxis.webp)
{: slot="bg" }
```
