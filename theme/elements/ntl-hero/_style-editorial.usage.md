# Redaktioneller Einstieg mit Footer-Slider

Der Slider liegt im `footer`-Slot und überlappt die Hero-Unterkante.
Die Komposition eignet sich für ein Magazin oder einen Themenüberblick.
Der zugehörige Slider verwendet `style-editorial`.

```markdown
## Neues aus der Praxis
{: layout="ntl-hero.style-editorial" }

Wissenswertes für Ihren Alltag.

### Aktuelle Themen
{: layout="nte-slider.style-editorial" section-slot="footer" }

#### Vorsorge

Informationen zur Vorsorge.

#### Beratung

Antworten auf häufige Fragen.
```
