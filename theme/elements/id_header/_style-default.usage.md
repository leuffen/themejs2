# Gemeinsamer Seitentitel im Website-Frame

Der feste Frame-Bereich hat die ID `header`. Bild, Titel und Beschreibung
kommen aus dem Layout beziehungsweise dessen Jekyll-Feldern. Eine
seitenweite Variant liefert die visuellen Werte.

```html
<header id="header" class="style-default container py-4">
  <h1>Unsere Praxis</h1>
  <p>Persönlich für Sie da.</p>
</header>
```
