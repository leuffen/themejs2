# Flexible Inhalts- und Seitenspalten

Die Komponente verwaltet ihre Inhaltsbereiche und responsive Anordnung.
Unterabschnitte bleiben Markdown; für eine einfache Bild-Text-Komposition
ist `ntl-2col` die erste Wahl.

```markdown
## Unsere Praxis
{: layout="ntl-columns" }

### Willkommen

Informationen zur Praxis.

### Kontakt
{: section-slot="end" }

Telefon und Sprechzeiten.
```
