# Kartenreihen

Der öffentliche Theme-Entry registriert alle Stile dieses Verzeichnisses.
`style-default` wird von der Komponente automatisch gewählt. Jeder Abschnitt
verwendet höchstens eine `style-*`-Klasse; die zugehörige Usage-Datei
beschreibt die jeweiligen Inhalte und Modifier.

```markdown
## Leistungen
{: layout="ntl-card-row" section-style="--cols: 6;" }

### Beratung

Wir klären gemeinsam die nächsten Schritte.

### Begleitung

Wir unterstützen die Umsetzung.
```
