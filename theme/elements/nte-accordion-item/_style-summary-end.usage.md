# Zusammenfassung unter den Details

`style-summary-end` gehört an das einzelne `nte-accordion-item`.
Die Komponente steuert Öffnen und Schließen; dieser Style ordnet nur die
öffentlichen Parts. Der Inhalt kann Metadaten eines Artikels oder ergänzende
Details eines Angebots enthalten.

```markdown
## Weitere Informationen
{: layout="nte-accordion" }

### Details einblenden
{: section-class="style-summary-end" }

Informationen zum Autor und zur Veröffentlichung.
```
