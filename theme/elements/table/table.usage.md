---
description: Sass-Entry für native Tabellen, Öffnungszeiten und Zeitpläne.
---

Die gemeinsame Theme-Basis lädt [style-default](_style-default.usage.md),
[style-open-hours](_style-open-hours.usage.md) und
[style-timeline](_style-timeline.usage.md).

## Beispiel

Die gemeinsame Theme-Basis muss geladen sein. Der vorhandene
Kramdown-Renderer erzeugt im Content eine native Tabelle;
eine zusätzliche Web Component oder Style-Klasse ist nicht erforderlich.

```markdown
| Leistung | Dauer |
| --- | --- |
| Beratung | nach Bedarf |
```
