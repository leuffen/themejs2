# Normale Aufzählung im Content

Ohne eigene `style-*`-Klasse wird die Nextrap-Baseline verwendet.
Die native Library-Klasse `.list` bleibt eine explizite Alternative;
Utilities und funktionale Styles können gezielt gewählt werden.

```markdown
- Erstgespräch
- Untersuchung
- Beratung
```
