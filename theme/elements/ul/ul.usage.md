description: Sass-Entry für native Aufzählungen und funktionale Listen-Styles.
---

Die gemeinsame Theme-Basis lädt [style-default](_style-default.usage.md)
und [style-specialties](_style-specialties.usage.md).

## Beispiel

Die gemeinsame Theme-Basis muss geladen sein. Der vorhandene
Markdown-Renderer erzeugt im Content eine native `ul`-Liste;
eine zusätzliche Web Component oder Style-Klasse ist nicht erforderlich.

```markdown
- Erstgespräch
- Untersuchung
- Beratung
```
