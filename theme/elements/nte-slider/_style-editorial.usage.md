# Artikel-Slider für den Hero-Footer

Wird im Footer eines `ntl-hero.style-editorial` eingesetzt. Content Pane
formt die Unterabschnitte zu Slides; Bild und Text bleiben Inhalte.
Navigation, Tastatur und Slide-Wechsel liefert `nte-slider`.

```markdown
## Aktuelle Beiträge
{: layout="nte-slider.style-editorial" }

### Vorsorge

![Beispielmotiv](/assets/vorsorge.webp)

Wissenswertes zur Vorsorge.

### Beratung

Ihre Fragen im Mittelpunkt.
```
