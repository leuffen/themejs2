# Einfacher Website-Abschluss

`#footer.style-default` verwendet die primäre Fläche mit zugehöriger
Kontrasttextfarbe. Navigation und Kontaktdaten bleiben editierbares
Markup; andere vollständige Frames können eigene Styles wählen.

```html
<footer id="footer" class="style-default">
  <div class="container py-3">
    <a href="/impressum.html">Impressum</a>
  </div>
</footer>
```
