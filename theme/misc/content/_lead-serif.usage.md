# Einleitung in Serifenschrift

`lead-serif` kennzeichnet einen hervorgehobenen Absatz im Content.
Die Schriftdatei für EB Garamond wird vom gemeinsamen Theme-Entry geladen;
Georgia und die System-Serifenschrift dienen als Fallback.

```markdown
## Unsere Praxis
{: layout="ntl-2col" }

Wir nehmen uns Zeit für Ihr Anliegen.
{: .lead-serif }
```

Die Klasse steuert nur den Text, keine Layout-Slots oder Spalten.
