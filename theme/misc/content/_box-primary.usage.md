# Content-Box

`box-primary` bleibt für vorhandene Content-Pane-Sections verfügbar und
ergänzt ausschließlich den Innenabstand.

```markdown
## Hinweis
{: layout="ntl-2col" }

### Gut zu wissen
{: layout=".box-primary" }

Hier finden Sie die ergänzenden Informationen.
```

Neue funktionale Kompositionen verwenden die dafür vorgesehenen NTL-Styles.
