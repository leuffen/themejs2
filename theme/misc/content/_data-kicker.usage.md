# Überschrift mit Kicker

`data-kicker` enthält den editierbaren Oberbegriff.
`kicker-line` ergänzt optional eine dekorative Linie.

```markdown
## Persönliche Beratung
{: layout="ntl-2col" data-kicker="Unsere Leistungen" .kicker-line }

Wir besprechen Ihre Fragen und die nächsten Schritte.
```

Das Pattern arbeitet an H1 bis H6 und ändert keine Content-Pane-Slots.
