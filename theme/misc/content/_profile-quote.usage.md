# Hervorgehobenes Zitat

`profile-quote` betont einen Absatz oder ein Blockquote. Die Schrift bleibt
kleiner als eine große Abschnittsüberschrift; der Inhalt bleibt editierbar.

```markdown
## Unsere Haltung
{: layout="ntl-2col" }

> Eine gute Entscheidung beginnt mit einem verständlichen Gespräch.
{: .profile-quote }
```

Die Klasse ergänzt die Typografie eines vorhandenen Inhaltsbereichs.
