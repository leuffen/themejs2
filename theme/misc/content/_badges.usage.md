# Text-Badges

`badges` nimmt einzelne Markdown-Absätze auf. Inhalt und Anzahl bleiben frei.

```markdown
## Auf einen Blick
{: layout="ntl-2col" }

---
{: layout=".badges" }

Persönlich

Verständlich

Verlässlich
```

Die Klasse nutzt die vorhandene Primary-Farbrolle und keine eigene Palette.
