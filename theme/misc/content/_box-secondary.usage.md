# Kompakte Unterabschnitte

`box-secondary` gehört an einen Container mit normalen H3-Sections.
Das bestehende Inhaltsmuster bleibt unter Misc; seine Palette stammt aus
den Nextrap-Tokens.

```markdown
## Häufige Themen
{: layout="ntl-2col" }

---
{: layout=".box-secondary" }

### Termine

Informationen zur Terminvereinbarung.

### Anfahrt

Informationen zum Praxisbesuch.
```
