# Avatare und Vertrauenshinweis

`trust-list` gestaltet einen Markdown-Absatz mit Bildern als überlappende
Avatargruppe. `trust-copy` ist der folgende Textabsatz.
Beide verwenden denselben Responsive-Zustand, etwa `sm:desktop`.

```markdown
## Gemeinsam erfolgreich
{: layout="ntl-hero.style-campaign" }

![Kundin](/assets/avatar-a.webp)
![Kunde](/assets/avatar-b.webp)
{: .trust-list .sm:desktop }

**Persönliche Erfahrungen**  
Rückmeldungen unserer Kundinnen und Kunden
{: .trust-copy .sm:desktop }
```

Die Bilder und Aussagen kommen aus dem Content. Das Pattern ergänzt keine
Bewertungen oder Zahlen.
