# Layouts

Alle Website-Layouts erben von `20_body`. Das gewählte Layout bindet
seine Navbar, den gemeinsamen Inhaltsbereich und seinen Footer statisch
ein.

| Layout | Navbar | Footer |
| --- | --- | --- |
| `website` | Default | Default |
| `website-mueller` | Default | Müller |
| `website-osman` | Osman | Osman |
| `website-raven` | Osman | Raven |
| `website-unify` | Unify | Unify |
| `website-navbar-only` | Default | – |
| `website-footer-only` | – | Default |
| `website-none` oder `blanco` | – | – |

`index` rendert Kategorie-Karten. `legal/legal` enthält den
Inhaltsrahmen für Rechtstexte.
