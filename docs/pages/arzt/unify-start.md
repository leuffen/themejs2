## Häufig gestellte Fragen
{: layout="ntl-2col.style-default" data-kicker="Gut zu wissen" section-style="--cols: 4;" }

Kurze Antworten auf die wichtigsten Fragen vor dem gemeinsamen Projektstart.

---
{: layout="3;nte-accordion.style-default" .aside }

#### Welche Inhalte können wir selbst bearbeiten?

Texte, Bilder, Links, Karten und ganze Abschnitte bleiben in Kramdown strukturiert und ohne Spezialeditor pflegbar.

#### Funktioniert das Theme auf Mobilgeräten?

Ja. Die NTL-Komponenten wechseln über ihre dokumentierten Modi in eine lesbare mobile Komposition.

#### Können bestehende Inhalte übernommen werden?

Bestehende Markdown-Inhalte lassen sich weiterverwenden und schrittweise den passenden Layouts zuordnen.

#### Ist das Theme an eine Branche gebunden?

Nein. Die Varianten beschreiben allgemeine Business-, Produkt- und Beratungsinhalte statt kundenspezifischer Daten.
